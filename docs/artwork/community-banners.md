# Community banners

Created with the built-in AI image generation tool for EMP's README. Both are promotional pixel-art illustrations.

- `support-banner.jpg` (in the emberville-mods repo's `docs/images/`): 1600 × 640, linking to https://buymeacoffee.com/quadh.
- `discord-banner.jpg` (in the emberville-mods repo's `docs/images/`): 1600 × 400, linking to https://discord.gg/EwTjQxEZPy.
- `support-banner-source.png` and `discord-banner-source.png`: original generated outputs.

Identity reference: the Quads Lab Valheim mods' support banner, using the same creator's curly hair, red glasses, goatee, lab coat and black coffee mug. The old Discord banner was a layout reference. EMP's cover was the reference for pixel art and the dungeon palette. Game names and Viking props are omitted from these new banners.

## Support banner refinement prompt

Use case: precise-object-edit Input image: edit target, pixel-art support banner. Change ONLY the image on the upper-left computer monitor: replace the blue Viking longboat blueprint with a cyan pixel-art TOP-DOWN DUNGEON MAP of stone rooms and passages connected by lines, with four small colored player dots and green code panels around it. No ship, no Viking symbol. Do not add text to the monitor. Preserve EVERYTHING else exactly: creator's face, curly highlighted hair, red glasses, white coat, hoodie, hand and black coffee mug, all title and CTA lettering, footer captions and icons, composition, lighting, pixel art, room, dimensions and margins. This is a single small local edit.

Exports: the support banner resized to 1600 × 640; the Discord source center-cropped to 4:1 and resized to 1600 × 400 with
nearest-neighbor interpolation; both saved as JPG (quality 90) in the emberville-mods repo's `docs/images/`, where every page
(Ember Multiplayer's, the mods repo's, Party Tricks' and Damage Colors') loads them from.
